# MacaqueBrain_MC_Atlas
Analysis scripts for the *** manuscript on multi-omics integration in the macaque motor cortex.



## Code Submit rules:
1.All analysis scripts should be categorized based on **Figure units** to ensure a clear organizational structure, making them easy to locate and manage.  
2.If a script corresponds to a specific figure, it should follow the naming format: **Figure Number + Description**, e.g., `"A_bulkPCA.py"`, to enhance readability and traceability.  
3.For tasks completed through **multi-party collaboration**, all contributors should **jointly review and refine** the submitted code, and **sign off** to ensure code quality and consistency.  
4.The repository may include **lightweight datasets for visualization** (<50MB) to facilitate reproducibility and streamline the analysis workflow.
