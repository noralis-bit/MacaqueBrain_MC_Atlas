# NICHES CellToCellSpatial Radius 50μm Workflow

This folder contains the reproducible code used to run NICHES on the human
motor cortex h5ad/Seurat data and to generate the downstream long table and
figures.

The code is split into two parts:

- `run_long_table/`: convert/split input data, run NICHES by region-layer, and
  export a nonzero long table.
- `plots/`: one figure type per script, all reading the exported long table.

Default paths point to the current analysis workspace:

```text
/sdd/bgi/wangzilu/00.motorcortex_stduio/motorcortex_proj/45.DT-CCC
```

## Main Output

The main long table generated by this workflow is:

```text
/sdd/bgi/wangzilu/00.motorcortex_stduio/motorcortex_proj/45.DT-CCC/niches_region_layer_radius100_custom_human_raw_celltocellspatial/niches_region_layer_radius100_celltocellspatial_long_nonzero.csv.gz
```

Each row is one directed spatial cell-pair edge within the radius cutoff and
one nonzero ligand-receptor event. The table is not filtered by p value or FDR;
NICHES raw CellToCellSpatial output does not provide those columns here.

During long-table export, the L4-like labels are harmonized:

```text
L3/5-IT.03 -> L4-IT.00
L3/5-IT.04 -> L4-IT.01
L3/5-IT.05 -> L4-IT.02
```

The same relabeling is also applied inside plotting scripts so figures remain
consistent even when testing from an older exported long table.

## Long Table Workflow

Run in the `deeptalk-env` conda environment on the workstation.

```bash
cd /sdd/bgi/wangzilu/00.motorcortex_stduio/motorcortex_proj/45.DT-CCC
source /sdd/bgi/wangzilu/miniconda3/etc/profile.d/conda.sh
conda activate deeptalk-env

# Optional if starting from h5ad.
Rscript run_long_table/00_convert_h5ad_to_seurat_rds.R \
  /sdd/bgi/wangzilu/00.motorcortex_stduio/motorcortex_proj/44.cross_main_region_cellchat/adata286.h5ad \
  adata286.seurat.rds

Rscript run_long_table/01_split_seurat_by_region_layer.R \
  adata286.seurat.rds \
  region_layer_rds

python run_long_table/02_prepare_custom_lr_database.py \
  --input-lr-db lr_db_human_with_pathway.csv \
  --output-lr-db lr_db_human_niches_custom.csv

bash run_long_table/04_run_all_region_layer_niches_celltocellspatial.sh \
  region_layer_rds/manifest.tsv 1 100 custom human raw lr_db_human_niches_custom.csv

Rscript run_long_table/05_export_celltocellspatial_long_nonzero.R \
  niches_region_layer_radius100_custom_human_raw_celltocellspatial \
  niches_region_layer_radius100_celltocellspatial_long_nonzero.csv.gz
```

## Plot Examples

```bash
python plots/01_plot_event_vectortype_jaccard_heatmap.py
python plots/02_plot_chord_by_layer.py
python plots/03_plot_cellpair_top6_interactions_by_layer.py
python plots/04_plot_cellpair_top6_pathways_by_layer.py
python plots/05_plot_cellpair_interaction_count_by_layer.py
python plots/06_plot_l4_like_source_stacked_bar.py
python plots/07_plot_l4_like_target_stacked_bar.py
python plots/08_plot_l4_like_celltype_percentage_l3s_l3d.py
python plots/09_plot_ast_l4_like_colocalization_and_cellmask.py
python plots/10_plot_layer_lr_dotplot_and_volcano.py
python plots/11_plot_lr_spatial_p100_overview.py
```

By default, scripts 03, 04, and 05 generate plots for:

```text
Ast.00->L2/3-IT.04
Ast.00->L4-IT.02
```

Scripts 06 and 07 count nonzero interaction records where L4-like cells are the
sending or receiving side, respectively. Script 08 counts cells directly from
the h5ad metadata and plots the percentage of all cells in `l3s` and `l3d`.
Script 09 plots Ast.00 colocalization with `L2/3-IT.04` and `L4-IT.02` on chip
`T578`, then renders cropped cellmask PNGs for the colocated cells. It requires
the workstation-local `range_compression` module and cellmask directory.
Script 10 builds an AnnData object from the NICHES wide table and makes the
layer LR dotplot and L3s-vs-L3d volcano plot. Script 11 combines the multi-LR
spatial P100 plotting workflow with the APP-SORL1 six-chip P100 overview.

## LR Database Notes

The full human LR database used for annotation is `lr_db_human_with_pathway.csv`
with columns `from`, `to`, `pathway`, and `type`. NICHES was run with a custom
database made from the first two columns only, saved as
`lr_db_human_niches_custom.csv`. Pathway-level plots map `event` back to
`pathway` using the full LR database; pathway is not inferred by NICHES.
